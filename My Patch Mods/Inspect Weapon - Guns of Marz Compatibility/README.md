## Fix 4.4 / v0.9.0 — 16.08.2026

- Установка **одиночного** обвеса выполняется только через «Осмотр оружия».
- Direct GoM WeaponPart: актуальный `ISUpgradeWeapon:new(character, weapon, part)` без старого аргумента `50`.
- UniversalAttachment: передаётся зарегистрированный `outcomeFullType`.
- Съёмный штык: установка/снятие из Inspect идут через штатные Gunworks `BayonetAttachmentContext` / `ISBayonetAttach` / `ISBayonetRemove`.
- ПКМ одной пушки: индивидуальные Add/Remove/Bayonet/Railing-команды скрыты.
- ПКМ реального стака/выделения 2+ пушек: остаётся массовое снятие всех безопасно снимаемых насадок и массовая разрядка.
- Старый hardcoded renderer Risky для Marz не вызывается; 177 имён предметов/насадок/магазинов имеют чистый UTF-8 fallback.
- FN FNC integrated stock использует существующую stock-иконку как UI fallback; fallback не перезаписывается `attachmentButton:render()`.
- Tidy Up Meister не перехватывает `riskyInspectAction`.

# Inspect Weapon - Guns of Marz Compatibility — Fix 4.4 / 0.9.0

Target: Project Zomboid Build 42.20.2.

Патч соединяет **Risky Inspect Weapon**, **Gunworks** и **Guns of Marz**, не копируя исходный мод Inspect Weapon и не меняя баланс оружия/обвесов.

## Что исправляет Fix 4.4

- Для GoM-оружия окно осмотра рисует только реальные модельные слоты. Пустой слот: **`Нет насадки`** + **`Требуется совместимая насадка`**; старые `Ничего`, raw PartType и кракозябры не используются.
- Названия слотов полные: `Верхняя планка`, `Нижняя планка`, `Дульный адаптер`, `Штык-нож`, `Встроенные сошки` и т.д.
- В заголовке самого Inspect Weapon русские сокращения типа `(пист.)`, `(ГВ)`, `(ШВ)`, `(ПП)` разворачиваются в полные слова. Это **локально для окна осмотра** и не раздувает обычный список инвентаря.
- Пустой слот открывает компактную **сетку иконок совместимых деталей**, как у исходной идеи Inspect Weapon, вместо длинного текстового списка.
- Для Guns of Marz скрыты дублирующие текстовые `Добавить насадку` / `Убрать насадку`; установка/снятие остаются доступны через Inspect Weapon.

## Совместимость и защита от неправильных насадок

- Direct `WeaponPart` проверяется по настоящему `MountOn` конкретного оружия.
- Та же проверка стоит в `ISUpgradeWeapon:isValid`, поэтому стороннее меню не может обойти её. Например, `MarzGuns.Beretta_Mount` нельзя поставить на `MarzGuns.AR15`.
- Простое уже сохранённое неправильное Rail/CanonMount может быть безопасно исправлено при осмотре, но патч не трогает permanent/universal детали и не разрывает dependency-tree.
- `RequiredAttachment`, `Railing`, `UpgradeExclusives`, `UniversalAttachment`, active-underbarrel и permanent/integrated правила Gunworks сохраняются.

## Инструменты и штык

- Исправная отвёртка ищется во всех доступных контейнерах B42: основной инвентарь, надетые/вложенные сумки и открытые соседние ящики/шкафы/контейнеры.
- Если отвёртка лежит рядом, она штатно переносится в инвентарь перед действием; вручную перекладывать её не нужно.
- **Съёмный штык-нож не требует отвёртки** и использует `ISBayonetAttach` / `ISBayonetRemove` Gunworks. Integrated fold/deploy не подменяется.

## Массовые действия и стаки

- Для одного GoM-оружия **нет** массового `Снять все насадки`: одиночная установка/снятие обвеса выполняется через «Осмотр оружия». Компактное `Разрядить` остаётся отдельной оружейной операцией.
- Только для реального стака/выделения из **2+ единиц**: `Оружие — групповые действия` -> `Снять насадки со всего оружия` / `Разрядить всё оружие`.
- Используются реальные предметы из `ISInventoryPane.getActualItems`, а не только dummy-строка стака.
- Оружие можно выбрать из рюкзака или открытого соседнего контейнера: нужные предметы/инструменты штатно переносятся для действия.
- Массовое снятие идёт child-first. После него detached-насадки возвращаются в исходный контейнер оружия; для bayonet учитывается преобразование обратно в новый knife item.

## Разрядка

Только штатные B42 timed actions:

- `ISEjectMagazine` — съёмный магазин;
- `ISUnloadBulletsFromFirearm` — внутренние патроны;
- `ISRackFirearm` — патронник/цикл/заклинивание.

Патрон из патронника не удаляется прямой записью: штатный `ISRackFirearm:removeBullet()` создаёт боеприпас в инвентаре.

## Runtime crash guard

Свежий лог показал повторяемый конфликт `Gunworks filterPermanentParts -> ISContextMenu.removeOptionByName -> CleanUI`. Fix 4.3 защищает `removeOptionByName` от sparse/повреждённых entries и восстанавливает правильные B42 `id` / `numOptions`.

## Границы

- Нет глобального сканирования всех ScriptItem каждый кадр.
- Нет ребаланса оружия/насадок.
- Нет переписывания `MountOn` исходных предметов.
- Inspect Weapon Workshop-мод остаётся отдельной обязательной зависимостью.
- Runtime-поведение после установки всё равно нужно проверить в игре на текущей сборке модов.
