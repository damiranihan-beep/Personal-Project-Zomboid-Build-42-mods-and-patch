# WATC v2.1 — native tooltip + точная совместимость

v2.1 не строит отдельный полный tooltip и не подменяет статы предметов.

## Основная схема

1. Для обычной насадки сохраняется её настоящий MountOn; на время отрисовки сокращаются только display name совместимых моделей.
2. Для магазина GoM его служебный FakeItemPistols/FakeItemRifles на время **одного render-вызова** заменяется списком конкретных моделей из данных GoM/Gunworks.
3. Сразу после render исходный список MountOn восстанавливается, даже если другой tooltip-hook выдаст ошибку.
4. Родной `item:DoTooltip` продолжает отвечать за вес, количество патронов, вместимость, боеприпас, состояние и прочие штатные строки.
5. Только дополнительный блок Guns of Marz локализуется: `Information` -> `Информация`, а строки характеристик берутся из уже существующих UI_MRT-переводов.
6. PL-4 / PS-1 / PM-2 / PRL-1 не переводятся старой картой WATC и остаются под контролем Attachment Rebalance.

## Не меняется
- постоянный MountOn;
- magazine profiles Gunworks;
- характеристики предметов;
- рецепты;
- механика глушителей.
