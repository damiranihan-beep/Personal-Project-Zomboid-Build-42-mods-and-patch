# Weapon Attachment Tooltip Cleaner 2.6 — Build 42.20.2

## Что исправлено после live-теста 2.5.1

- 2.5.1 больше не спамит NPE при наведении — этот фикс сохранён.
- Исправлена причина пустого собственного списка совместимости: отображаемый список теперь берётся из snapshot-карты, собранной прямо из текущих scripts Guns of Marz и Homemade Suppressors, а не зависит от конвертации Java `getMountOn()` в Lua.
- Для магазинов fake-group больше не показывается расплывчатое `Пистолеты / револьверы`: строится точная обратная совместимость по `MagazineType/ModelWeaponPart` (например, Hi-Power 13 -> `Browning Hi-Power`, M92FS 15 -> `Beretta M92FS`).
- Для `Picatinny_Rail` берётся реальный список оружия из `UniversalAttachments.lua`, поэтому вместо `Винтовки / дробовики` будут конкретные модели через `/`.
- Для TA28/TR-1/прочих насадок выводятся реальные совместимые модели через ` / ` с переносом длинной строки.
- Длинные русские суффиксы типа `— штурмовая винтовка` убираются только в нашем компактном списке.
- Реальный MountOn не меняется: runtime-список используется только для безопасного временного скрытия штатного значения и немедленно восстанавливается.
- Штатный заголовок `Можно закрепить/установить на` гасится переводом WATC; WATC теперь явно грузится после `MyRussianTranslations`.
- Show Weapon Stats Plus и Realistic Combat не изменялись.
