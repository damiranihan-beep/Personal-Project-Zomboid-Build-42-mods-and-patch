# Weapon Attachment Tooltip Cleaner

Небольшой UI-патч для Project Zomboid Build 42.20.2.

Что делает:
- не меняет `MountOn` у предметов во время рендера;
- убирает длинную горизонтальную строку совместимости у оружейных обвесов;
- показывает совместимое оружие вертикальным списком;
- позволяет другим нашим патчам зарегистрировать свои точные списки совместимости.

Это касается `WeaponPart`/оружейных обвесов. Горячие слоты, крепление к поясу/рюкзаку и другие системы экипировки не используют этот патч.


Почему отдельный мод:
- в ванильном Build 42 `MountOn` используется для совместимости `WeaponPart` с оружием;
- моды могут использовать `MountOn` и для своих служебных/fake-предметов, поэтому патч не удаляет параметр из скриптов;
- он меняет только отображение строки в tooltip и не затрагивает реальную возможность установить обвес.
