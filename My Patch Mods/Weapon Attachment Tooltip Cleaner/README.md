# Weapon Attachment Tooltip Cleaner v1.5 TEST

Этот мод отвечает **только за UI совместимости насадок Guns of Marz**.

Что делает:
1. Даёт игре построить обычный tooltip предмета.
2. Убирает длинную горизонтальную строку `Можно закрепить на: ...`.
3. Рисует новую строку `Можно закрепить на:`.
4. Под ней выводит **каждую совместимую модель отдельной строкой вниз**.

Что принципиально НЕ делает:
- не вызывает `setMountOn`;
- не очищает и не подменяет MountOn;
- не меняет совместимость установки;
- не меняет характеристики прицелов/обвесов;
- не содержит механику глушителей;
- не добавляет собственные stat-tooltip строки.

Для магазинов и насадок, у которых Guns of Marz использует FakeItem-категории, v1.5 держит собственную read-only карту совместимости, полученную из исходных скриптов Guns of Marz. Она используется только для отображения вертикального списка.
