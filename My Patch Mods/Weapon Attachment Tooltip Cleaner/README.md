# Weapon Attachment Tooltip Cleaner

Current version: **v1.1** — Project Zomboid Build 42.20.2

Маленький UI-патч. Он скрывает **только** стандартную строку совместимости
`Можно закрепить на: ...`, которую `WeaponPart` строит из `MountOn`.

Все остальные строки tooltip остаются под управлением ванили и исходных модов.
Мод специально не строит собственный список совместимых стволов.

Load order: после Guns of Marz и после Homemade Suppressors.
