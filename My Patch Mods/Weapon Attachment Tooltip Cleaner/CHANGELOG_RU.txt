Weapon Attachment Tooltip Cleaner v1.1 — 14.08.2026

ИСПРАВЛЕНО ПОСЛЕ ТЕСТА v1.0
- v1.0 делал слишком много: подменял весь ISToolTipInv.render для подходящих предметов,
  заново строил layout и добавлял собственный список совместимости.
- Из-за этого могли пропадать штатные строки: вес, общий вес, патроны в магазине,
  тип боеприпасов и строки, которые добавляют другие моды.
- Собственный вертикальный список также создавал дублирование и странную/битую строку-заголовок.

v1.1 ДЕЛАЕТ ТОЛЬКО ОДНО:
- на время штатного render временно передаёт WeaponPart MountOn = nil;
- вызывает ОРИГИНАЛЬНЫЙ tooltip renderer без собственной перерисовки;
- сразу возвращает исходный MountOn.

НЕ УДАЛЯЕТСЯ:
- Вес / Общий вес;
- Патронов в магазине;
- Тип боеприпасов;
- Тип предмета;
- Mod: ...;
- характеристики и описания Guns of Marz;
- любые другие строки ванили/модов.

УДАЛЯЕТСЯ ТОЛЬКО:
- строка «Можно закрепить на: ...» / «Can be attached to: ...», которую WeaponPart строит из MountOn.

ТЕХНИЧЕСКИ:
- Java ArrayList больше НЕ очищается через :clear();
- полный ISToolTipInv.render больше НЕ заменяется собственной копией;
- при ошибке API мод fail-open и отдаёт оригинальный tooltip.
