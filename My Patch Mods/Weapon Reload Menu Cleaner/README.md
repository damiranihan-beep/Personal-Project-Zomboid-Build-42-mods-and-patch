## Текущая версия: 1.2.0 / Fix 4.4

# Weapon Reload Menu Cleaner — 1.2.0

Private Build 42.20.2 compatibility patch.

### Fix 4.4 — магазины

- Один непустой магазин получает гарантированное **«Разрядить магазин»** даже если он лежит на полу или в открытом ящике: перед штатным timed action он переносится во временный рабочий инвентарь и затем возвращается.
- Реальный стак/выделение из **2+ магазинов** получает **«Магазины — групповые действия»**:
  - `Разрядить все магазины`;
  - `Зарядить все магазины`.
- Массовая зарядка видит совместимые патроны в инвентаре, на полу и в открытых контейнерах, заранее резервирует конкретные патроны между магазинами и сохраняет Gunworks Ammo family/profile.
- Частично заряженный магазин не меняет тип патрона; пустой выбирает первый реально доступный совместимый тип в порядке Gunworks.

Для обычного огнестрела патч сводит пересекающиеся ванильные/Picking Meister пункты разрядки в одно **`Разрядить оружие >`** с вариантами магазина/патронника и использует только штатные `ISEjectMagazine`, `ISUnloadBulletsFromFirearm`, `ISRackFirearm`.

Для **Guns of Marz** текстовый submenu больше не создаётся: после удаления дублей управление отдаётся `Inspect Weapon - Guns of Marz Compatibility`, который показывает компактное **`Разрядить`** и групповое **`Разрядить всё оружие`** для стака.

Исправлена нормализация `ISContextMenu.options` после удаления/перестановки: option IDs остаются 1-based, а `numOptions` хранит следующий свободный индекс (`N + 1`).

Заклинивание и обычное ручное передёргивание без патрона в патроннике остаются отдельными действиями.
