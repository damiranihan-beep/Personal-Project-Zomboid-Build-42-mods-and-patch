# Guns of Marz Attachment Rebalance 2.0.0

Первый полный релиз утверждённой системы поколений.

## Реализовано
- 25 tiered attachment ID с новыми stat registry entries;
- I–VII названия и U-маркер уникальных предметов;
- новые tooltips под фактические planned stats;
- масштабирование существующих optional attachment spawn rolls;
- масштабирование существующих standalone loot weights;
- сохранение исходных mount requirements и всех не-tiered предметов.

## Не реализуется намеренно
- новый loot route для предмета, которого не было в standalone loot;
- изменение suppressor balance;
- изменение MountOn;
- изменение встроенных частей оружия;
- изменение U-статов/редкости.

См. корневой `FINAL_DAY_RELEASE_2026-08-15_RU.md` и утверждённый Excel в `Planning/`.
