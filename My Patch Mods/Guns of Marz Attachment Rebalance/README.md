# Guns of Marz Attachment Rebalance

Отдельный мод полного ребаланса **stock Guns of Marz** для Project Zomboid Build 42.20.2.

## v2.0.0 — утверждённая система поколений

- Пользовательская иерархия `I–VII` применяется к лазерам, пистолетным прицелам, компактной оптике, увеличительной оптике и передним рукояткам.
- `U` = уникальный предмет вне линейной шкалы: PRL-1, Booster и сошки сохраняют STOCK-механику/цифры/редкость.
- Названия предметов получают префикс поколения без изменения item ID.
- Более высокие поколения постепенно получают/сохраняют полный набор полезных параметров своей категории.
- Для увеличительной оптики сохраняется trade-off: сильнее Hit/Crit/Sight = медленнее Aiming Time.

## Редкость

Коэффициенты к существующим STOCK-роллам/весам: `I 1.60`, `II 1.35`, `III 1.10`, `IV 0.90`, `V 0.70`, `VI 0.50`, `VII 0.35`, `U 1.00`.

- Спавн уже установленной насадки: сохраняется каждый оружейный STOCK-ролл автора, меняется только его шанс.
- Отдельный лут: сохраняются исходные контейнеры и относительные веса автора, масштабируется только вес конкретной tiered-насадки.
- Новые пути спавна не создаются.

## Границы проекта

Мод **не трогает**:
- заводские и самодельные глушители;
- MountOn / совместимость установки;
- Weapon Attachment Tooltip Cleaner;
- встроенные приклады/сошки оружия;
- крепления, фонари, дульные устройства, штыки и прочие предметы без назначенного поколения.

Подробная утверждённая таблица `было → стало`, включая 685 STOCK-роллов по оружию, лежит в `Planning/Guns_of_Marz_REBALANCE_STATS_AND_SPAWN_APPROVED_2026-08-15.xlsx`.
