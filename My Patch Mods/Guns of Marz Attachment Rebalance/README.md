# Guns of Marz Attachment Rebalance

Отдельный мод баланса обвесов Guns of Marz.

Версия 1.0.1 меняет только четыре пистолетных прицела:
- PL-4 — I поколение: +1% Hit / Crit / Sight Range;
- PS-1 — II поколение: +3%;
- PM-2 — III поколение: +6%;
- PRL-1 — IV поколение: +10%.

Мод **не** содержит механику самодельных глушителей и **не** скрывает строку «Можно закрепить на».
Для визуальной очистки совместимости используется отдельный `Weapon Attachment Tooltip Cleaner`.

Технически мод не копирует целиком `MarzWeapons/ItemTooltipsTable.lua`: он загружает оригинальную таблицу Guns of Marz и заменяет только 4 нужные записи. Это уменьшает риск конфликтов при обновлении Guns of Marz.


**v1.0.1:** отдельная иконка прицела/ребаланса; механика не изменена.
