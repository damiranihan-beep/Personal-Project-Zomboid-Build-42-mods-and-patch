# Guns of Marz Core Fixes

Отдельный compatibility/bug-fix слой. Не относится к балансу насадок, самодельным глушителям или UI Cleaner.

## v1.0

Исправляет FN FNC:

- встроенный складной приклад больше не должен появляться в `Убрать насадку`;
- используются штатные Gunworks `PreventRemovals`, без переписывания Guns of Marz;
- если в текущем сохранении приклад уже сняли, при загрузке FNC в инвентаре/руках проверяется и штатный `FoldingStock.RestoreFoldedStockState()` возвращает встроенный приклад;
- отдельный уже выпавший служебный предмет не удаляется автоматически — его можно выбросить после проверки.
