# Guns of Marz Core Fixes

Отдельный compatibility/bug-fix слой. Не относится к балансу насадок, самодельным глушителям или UI Cleaner.

## v1.1

Исправляет две подтверждённые дыры в stock-реестре несъёмных встроенных деталей Guns of Marz:

- FN FNC — встроенный складной приклад (`StockIntegrated`);
- M24 — встроенные складные сошки (`BipodIntegrated`).

Для обеих систем:

- отсутствующие state-предметы зарегистрированы через штатный Gunworks `PreventRemovals`;
- обычное меню «Убрать насадку» больше не должно предлагать эти встроенные детали;
- если служебную встроенную деталь уже сняли в существующем сохранении, при загрузке оружия в инвентаре/руках вызывается штатное восстановление Gunworks (`FoldingStock` / `FoldingBipod`);
- отдельный уже выпавший служебный предмет автоматически не удаляется;
- характеристики, складывание/раскладывание и другие механики не переписываются.
