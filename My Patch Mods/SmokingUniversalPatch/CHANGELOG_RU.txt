Smoking Universal Patch 42.20.2 — v1.4.1 Final

1. Where Are My Zang Cigs:
- стартовая выдача курильщику переведена на совместимую с Build 42.20.2 проверку трейта;
- выдаётся пачка Base.CigarettePack с 3–9 сигаретами и Base.LighterDisposable с 6–24 использованиями (границы ZombRand сохранены как в старом патче);
- механика увеличенного мирового спавна НЕ дублируется: оригинальный Where Are My Zang Cigs уже умножает существующие шансы сигарет на x2 и добавляет сигареты в дополнительные таблицы лута/инвентарь зомби;
- старый Where Are My Zang Cigs 42.13+ patch должен быть отключён, его startup-fix поглощён этим патчем.

2. Smoking Sounds Overhaul:
- удалена опасная повторная подмена SmokingSoundsOverhaulActions.lua;
- патч больше не переопределяет ISEatFoodAction и ISTakePillAction;
- обычное курение остаётся полностью на оригинальном SSO;
- устранена причина двойного запуска SSO scheduler/playback, которая могла подвешивать игру в v1.3 Lite.

3. Курение с пачки:
- для Base.CigarettePack используется штатный путь Build 42.20.2 через ISTakePillAction;
- пункт контекстного меню называется «Курить с пачки сигарет»;
- если ванильный пункт уже создан, патч только переименовывает его;
- если другой мод убрал пункт, патч точечно восстанавливает его только для Base.CigarettePack;
- проверка наличия спичек/зажигалки/открытого огня остаётся ванильной;
- оригинальный Smoking Sounds Overhaul видит ISTakePillAction один раз и может проигрывать свои звуки без двойной обёртки.

Что проверить в игре:
1) Новый персонаж с трейтом «Курильщик» получает стартовую пачку и зажигалку.
2) В мире сигареты продолжают появляться чаще благодаря оригинальному WAMZ.
3) ПКМ по пачке -> «Курить с пачки сигарет».
4) Курение из пачки работает со спичками и зажигалкой и проигрывает SSO-звуки.
5) Обычная отдельная сигарета по-прежнему курится без зависания.

4. Финальная правка v1.4.1:
- исправлено битое отображение названия действия в русском интерфейсе;
- текст «Курить с пачки сигарет» теперь берётся через штатную систему локализации Project Zomboid, а не хранится кириллицей прямо в Lua;
- механика курения не изменялась после успешного игрового теста.
