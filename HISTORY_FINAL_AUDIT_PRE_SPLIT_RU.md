# FINAL AUDIT — Project Zomboid Build 42.20.2

Date: 2026-08-14

## Package status

Полный GitHub-ready репозиторий содержит все пять текущих проектов. В этом проходе изменены три из них; два остальных сохранены из последнего полного пакета.

### Homemade Suppressors for Guns of Marz — Fix 3.11
- Сохранён игровой баланс/звук/поломка/рецепты Fix 3.10.
- Рабочий шум: plastic -45%, can -55%, pipe -65%.
- Рабочие штрафы урона/дальности/шанса крита сохранены.
- Автоматический fire fail-safe сохранён.
- Tooltip-provider больше не публикует видимые списки совместимости; совместимость остаётся только скрытой метаинформацией для фильтрации UI.

### Weapon Attachment Tooltip Cleaner — v1.3
- `Тип` остаётся видимым.
- Полностью скрывается весь compatibility block: строка `Можно закрепить/прикрепить на`, категории оружия и конкретные модели, принадлежащие этому блоку.
- MountOn не изменяется и не очищается.
- Удалён старый ammo fallback v1.2, который мог показывать raw `marzguns:bullet_*` и кракозябры.
- WATC больше не добавляет собственные AmmoCount/AmmoType строки.

### Realistic Combat — Fix 3.5
- По свежему console.txt повторяющиеся ERROR происходили именно при втором/off-hand ударе.
- Удалены обращения, которые пытались записывать Java userdata `AttackVars.bCloseKill` / `CloseKillMove` как Lua-таблицу.
- Сохранены vanilla pressedAttack/SwipeStatePlayer, чередование рук, травмы левой руки и перенос мышечной нагрузки.
- Принудительное подавление off-hand finisher старым методом отключено, потому что именно этот путь ломал второй удар в Build 42.20.2.

### Russian Translation Collection — v4.4.0
- Сохранена без изменений из последнего полного GitHub-ready пакета.

### Smoking Universal Patch — v1.4.3
- Сохранён без изменений из последнего полного GitHub-ready пакета.
