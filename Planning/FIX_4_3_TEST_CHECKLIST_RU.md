# Fix 4.3 — игровой чеклист

Статическая проверка не заменяет runtime. После установки TEST-архива пройти пункты ниже и сохранить свежий `console.txt`.

## Inspect Weapon

- P226: заголовок в Inspect = `SIG Sauer P226 (пистолет)`, не `(пист.)`.
- AR-15: заголовок в Inspect = `AR-15 (гражданская винтовка)`, не `(ГВ)`.
- Нет кракозябр `!B2>;`, `03078=`, `C;L=K9...` и красных зависших tooltip.
- Пустые реальные слоты: `Нет насадки` / `Требуется совместимая насадка`.
- В слотах нет raw `RailUp`, `BayonetKnife`, `UI_GOMIW_*`.
- Нажать пустой слот: появляется компактная сетка иконок совместимых деталей.
- В обычном ПКМ GoM-оружия нет длинных `Добавить насадку` / `Убрать насадку`.

## MountOn / инструменты

- AR-15 + Beretta mount: установка невозможна.
- Открыть старый AR-15, на котором уже ошибочно сохранён Beretta mount: Inspect должен убрать только эту invalid rail без повреждения других насадок.
- Положить отвёртку только в открытый соседний ящик: установка/снятие обычной GoM-насадки должно сработать без ручного перекладывания отвёртки.
- Убрать отвёртку полностью: обычная GoM-насадка не ставится/не снимается.
- Штык-нож: поставить и снять БЕЗ отвёртки; integrated fold/deploy отдельно не ломается.

## Bulk / контейнеры / стак

- Положить оружие с несколькими насадками в рюкзак: `Снять все насадки` работает без ручного взятия оружия.
- Положить его в открытый соседний ящик: действие тоже работает; отвёртка может лежать в другом доступном открытом контейнере.
- После снятия насадки возвращаются в исходный контейнер оружия; штык возвращается туда уже как нож.
- Создать grouped row из 3 AR-15: `Оружие — групповые действия` содержит `Снять насадки со всего оружия` и/или `Разрядить всё оружие`; действие проходит по всем трём реальным экземплярам.

## Разрядка

- Одиночное меню = `Разрядить`, без `Разрядить AR-15 ...`.
- Съёмный магазин извлекается.
- Внутренний магазин разгружается.
- Патрон из патронника после действия лежит в инвентаре, а не исчезает.
- Проверить jammed weapon: отдельное устранение заклинивания/ручной rack не должен исчезнуть из-за Cleaner.

## Контекстное меню / SESSION error

- Несколько раз открыть ПКМ на P226/AR-15 с разными комбинациями насадок и без них.
- В новом логе НЕ должно быть стека `removeOptionByName -> Gunworks filterPermanentParts -> CleanUI`.
