## 1. Inspect Weapon / Guns of Marz

1. Убрать из блока навесного оборудования кракозябры, raw keys и старые бессмысленные строки `Ничего`.
2. Для пустого поддерживаемого слота выводить `Нет насадки` + `Требуется совместимая насадка`.
3. Названия слотов — полные русские, без технических PartType/инициалов.
4. При открытии осмотра разворачивать сокращённые типы самого оружия (`пист.`, `ГВ`, `ШВ`, `ПП`...) в полные названия только в этом окне.
5. Установка из Inspect Weapon — через сетку иконок, как в исходном Inspect Weapon, а не через длинный текстовый список.
6. Для GoM убрать дублирующие текстовые контекстные `Добавить/Убрать насадку`.
7. Строго соблюдать direct `MountOn`. Пистолетная Beretta rail не должна быть доступна AR-15 ни из Inspect, ни через сторонний menu/timed action.
8. Уже сохранённый заведомо неправильный простой rail/adapter чинить осторожно, не трогая permanent/universal/dependency детали.
9. Отвёртка должна находиться в основном инвентаре, рюкзаках и открытых доступных соседних контейнерах; при необходимости переноситься автоматически.
10. Съёмный штык-нож — quick-release без отвёртки. Integrated fold/deploy не переписывать.
11. `Снять все насадки` должно работать для оружия из других ячеек/контейнеров и не требовать ручного перекладывания пользователем.
12. После bulk detach насадки должны вернуться в исходный контейнер оружия, а не оставаться в основном инвентаре.
13. Для стака из нескольких реальных оружий — действия на весь стак: `Снять насадки со всего оружия`, `Разрядить всё оружие`.
14. Одиночное действие разрядки называется просто `Разрядить`, без повторения имени оружия.
15. Разрядка должна корректно обрабатывать detachable magazine, internal ammo, chambered round и jammed/rack state штатными timed actions.
16. Патрон из патронника не должен аннигилироваться: не сбрасывать chamber state вручную; использовать штатный rack/eject path.
17. Устранить свежий `_SESSION`/Lua error, возникший при контекстном меню: `Gunworks filterPermanentParts -> ISContextMenu.removeOptionByName -> CleanUI`.
18. Сохранить Tidy Up Meister exclusion для самого `riskyInspectAction`.
