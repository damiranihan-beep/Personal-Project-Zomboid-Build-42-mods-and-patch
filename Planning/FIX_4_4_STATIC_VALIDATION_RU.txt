FIX 4.4 — СТАТИЧЕСКАЯ ПРОВЕРКА
Дата: 16.08.2026
Целевая версия: Project Zomboid Build 42.20.2

ВАЖНО:
Это статическая проверка кода/структуры и логическая симуляция. Она не заменяет runtime-тест внутри игры.

1. ВЕРСИИ / ID
- GOM_InspectWeaponCompat: id сохранён, версия 0.9.0, modversion=9.
- WeaponReloadMenuCleaner: id сохранён, версия 1.2.0, modversion=3.
- WeaponAttachmentTooltipCleaner: id сохранён, версия 2.8.0, modversion=21.
- Игровые ID исходного Guns of Marz не переименовывались.

2. INSTALL / DETACH
- Прямая GoM-установка использует актуальный ISUpgradeWeapon:new(character, weapon, part), без legacy-аргумента 50.
- UniversalAttachment передаёт outcomeFullType четвёртым аргументом.
- Съёмный штык использует штатный BayonetAttachmentContext / ISBayonetAttach / ISBayonetRemove.
- Перед одиночной установкой отвёртка повторно проверяется до переноса предметов.
- Временно взятая из соседнего контейнера отвёртка ставится на возврат в исходный контейнер.
- Mass detach доступен только при 2+ реальных оружиях.
- Для смешанного плана bayonet + обычные детали отвёртка повторно экипируется перед каждым обычным ISRemoveWeaponUpgrade.
- Mass detach не использует direct item mutation.

3. КОНТЕКСТНОЕ МЕНЮ
- Для Marz удаляются все верхнеуровневые копии индивидуальных Add Weapon Upgrade / Remove Weapon Upgrade / Attach Bayonet / Remove Bayonet / Railing Options.
- Установка одиночной насадки остаётся только в «Осмотр оружия».
- Для 2+ реальных оружий сохраняется «Снять насадки со всего оружия».
- Реальный stack раскрывается через ISInventoryPane.getActualItems.

4. МАГАЗИНЫ
- Одиночная разрядка доступна из inventory/floor/open container через transfer-safe путь.
- 2+ реальных магазинов получают mass unload и mass load.
- Для mass load сначала собирается общий пул конкретных патронов из доступных контейнеров, затем физические предметы резервируются между магазинами.
- Частично заряженный магазин не меняет текущий тип боеприпаса.
- Пустой магазин выбирает первый реально доступный совместимый тип Gunworks Ammo family.
- Gunworks MagazineAmmoProfileSetter + расширенный ISLoadBulletsInMagazine используются для ammo profile / AmmoList пути.

5. ЛОГИЧЕСКАЯ СИМУЛЯЦИЯ MASS LOAD
Сценарий:
- 15 магазинов;
- 5 частично заряжены FMJ по 5/15;
- 5 пустых;
- 5 частично заряжены HP по 10/15;
- пул: 100 FMJ + 40 HP = 140 физических патронов.

Результат симуляции алгоритма резервирования:
- создано 15 планов зарядки;
- зарезервировано ровно 140 уникальных физических патронов;
- повторного резервирования одного патрона нет;
- все частично заряженные магазины сохранили свой текущий тип.
Результат: PASS.
