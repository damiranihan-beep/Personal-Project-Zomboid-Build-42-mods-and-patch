# Fix 4.4 — общее ТЗ и границы

Дата: 16.08.2026  
Цель: исправить текущий Inspect Weapon + Guns of Marz и добавить безопасные массовые операции без изменения баланса оружия.

## 1. Обвесы

- **Установка любой одиночной насадки — только через «Осмотр оружия».**
- Через обычный ПКМ одной пушки не должно оставаться индивидуальных:
  - Add/Remove Weapon Upgrade;
  - Attach/Remove Bayonet;
  - Railing attach/remove.
- Складные/раскладные встроенные детали остаются штатной механикой Gunworks.
- Direct GoM WeaponPart обязан пройти точный `MountOn`, занятость PartType, RequiredAttachment и exclusives.
- Обычные съёмные насадки требуют отвёртку; отвёртка может лежать в доступном открытом контейнере и временно переносится штатным действием.
- Съёмный штык следует штатной Gunworks quick-release логике и не получает искусственное требование отвёртки.
- Для **реального стака/выделения 2+ оружия** оставить массовое «Снять насадки со всего оружия».
- Массовое снятие идёт по реальным предметам, child-first, не снимает permanent/integrated/Clip/активный underbarrel и возвращает оружие/снятые детали в исходную ячейку, где это безопасно.

## 2. Разрядка оружия

- Работает из инвентаря, пола и открытого контейнера.
- Для 2+ оружия — массовое «Разрядить всё оружие».
- Используются штатные `ISEjectMagazine`, `ISUnloadBulletsFromFirearm`, `ISRackFirearm`; патронник не очищается прямой записью.

## 3. Магазины

- Непустой одиночный магазин можно разрядить из любой доступной ячейки.
- Для реального стака/выделения 2+ магазинов:
  - «Разрядить все магазины»;
  - «Зарядить все магазины».
- Массовая зарядка видит совместимые патроны в доступных инвентаре/полу/открытых контейнерах.
- Конкретные патроны резервируются между магазинами до постановки actions — один физический патрон нельзя обещать двум магазинам.
- Частично заряженный магазин сохраняет текущий тип боеприпаса.
- Пустой магазин выбирает первый реально доступный тип из своей Gunworks Ammo family.
- Gunworks `AmmoList` / ammo profile не обходятся прямым изменением счётчика.

## 4. UI / кракозябры

- Для Marz-оружия не вызывать старые шесть hardcoded строк Risky.
- Имена текущих Marz предметов/WeaponPart/магазинов имеют чистый UTF-8 fallback.
- Внутри Inspect короткие типы оружия должны разворачиваться в читаемый вид.
- FN FNC integrated stock: upstream 3D ModelWeaponPart сохранён; при отсутствии Icon используется UI fallback, который не должен исчезать на следующем render.
- Tooltip Cleaner скрывает весь видимый `MountOn`/Can-attach блок, но сразу восстанавливает исходный gameplay `MountOn`.

## 5. Что не менять

- Баланс оружия/насадок.
- Реальные MountOn/совместимость.
- ID существующих модов.
- Исходный Workshop Inspect Weapon: это по-прежнему зависимость, а не скопированный мод.
