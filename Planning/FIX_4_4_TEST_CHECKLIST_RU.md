# FIX 4.4 — тест-чеклист

Дата: 16.08.2026  
Build: Project Zomboid 42.20.2

Цель этого прохода — проверить именно исправления установки обвесов, массовых действий, магазинов и UI. Старые второстепенные тесты не смешивать с этим проходом.

## 0. Подготовка

1. Полностью закрыть Project Zomboid.
2. Наложить TEST Fix 4.4 поверх текущих пользовательских модов.
3. Запустить игру заново.
4. Использовать текущий чистый тестовый мир; новый мир нужен только если текущий тест уже загрязнён старыми ошибочными предметами/UI.
5. После теста сохранить свежий `console.txt`.

## 1. Одна пушка — установка только через «Осмотр оружия»

На одном GoM-пистолете иметь рядом/в инвентаре 2–3 реально совместимые насадки и отвёртку.

- Открыть «Осмотр оружия».
- Нажать пустой слот и убедиться, что показываются только совместимые кандидаты.
- Установить насадку из собственного инвентаря.
- Снять её через «Осмотр оружия».
- Поставить обратно.
- Повторить для ещё 1–2 типов насадок.
- Повторить установку, когда насадка и/или отвёртка лежит в открытом соседнем ящике.

Ожидание:
- direct GoM WeaponPart устанавливается;
- universal-насадка устанавливается через свой Gunworks outcome;
- обычная насадка требует отвёртку;
- после действия отвёртка из соседнего контейнера возвращается туда;
- несовместимая насадка не предлагается.

## 2. Штык

- Поставить съёмный штык через «Осмотр оружия».
- Снять его через «Осмотр оружия».
- Снова поставить.
- Проверить без отвёртки.

Ожидание:
- съёмный штык использует штатный quick-release Gunworks и не требует искусственной отвёртки;
- установка и снятие работают в обе стороны.

## 3. Обычный ПКМ оружия

ПКМ по одной GoM-пушке и по stack/выделению нескольких GoM-пушек.

Не должно быть индивидуальных:
- «Добавить насадку»;
- «Снять насадку»;
- Attach/Remove Bayonet;
- Railing Options.

Допустимо:
- штатное сложить/разложить встроенную деталь;
- разрядка;
- для 2+ оружия — отдельное массовое снятие насадок.

## 4. Массовое снятие обвесов — 4 пистолета

В одном ящике/ячейке подготовить 4 GoM-пистолета, на каждом по 1–3 съёмных обвеса.

- ПКМ по общему stack/выделению.
- «Оружие — групповые действия» → «Снять насадки со всего оружия».

Ожидание:
- обрабатываются все четыре реальные единицы, а не только первая;
- child-зависимости снимаются в безопасном порядке;
- permanent/integrated/Clip не снимаются;
- обычные насадки требуют отвёртку;
- смешанный набор «штык + обычные насадки» не ломает последующие снятия;
- оружие и снятые детали возвращаются в исходную ячейку, где это возможно;
- отвёртка, временно взятая из открытого соседнего контейнера, возвращается обратно.

## 5. Один магазин — любая ячейка

Частично зарядить магазин.

Проверить:
- в собственном инвентаре;
- на полу;
- в открытом ящике.

ПКМ → «Разрядить магазин».

Ожидание:
- магазин полностью разряжается;
- для пола/ящика он временно переносится штатным действием и возвращается в исходную ячейку;
- патроны не исчезают.

## 6. Stack из 15 магазинов — массовая разрядка

Подготовить 15 магазинов с разным остатком патронов.

- Проверить stack в инвентаре.
- Проверить stack на полу/в ящике.
- «Магазины — групповые действия» → «Разрядить все магазины».

Ожидание:
- обработаны все 15 реальных магазинов;
- каждый имеет 0 патронов после завершения;
- ни один магазин не пропал и не остался случайно в другом контейнере.

## 7. Stack из 15 магазинов — массовая зарядка

Подготовить пустые и частично заряженные совместимые магазины. Разложить патроны между собственным инвентарём и открытыми доступными контейнерами.

- «Магазины — групповые действия» → «Зарядить все магазины».

Ожидание:
- зарядка проходит по всем реальным магазинам, пока хватает патронов;
- один физический патрон не расходуется дважды;
- частично заряженный магазин сохраняет текущий тип боеприпаса;
- пустой магазин выбирает реально доступный совместимый тип из Gunworks Ammo family;
- при нехватке патронов остаток распределяется без создания патронов из воздуха;
- магазины возвращаются в исходные ячейки.

## 8. Массовая разрядка оружия

Подготовить 3+ пушек с:
- вставленными магазинами;
- патронами во внутренних магазинах, где применимо;
- патроном в патроннике.

Проверить из инвентаря, пола/ящика.

Ожидание:
- «Разрядить всё оружие» проходит по каждой реальной пушке;
- магазин извлекается штатным действием;
- внутренний магазин выгружается штатным действием;
- патронник очищается через `ISRackFirearm`, без прямого удаления патрона;
- оружие возвращается в исходную ячейку.

## 9. UI / кракозябры

Проверить P226, AR-15/FNC и Benelli M4 или другое оружие с большим набором слотов.

Ожидание:
- нет старых шести ghost-строк Risky;
- нет кракозябр вместо названий обвесов;
- нет raw `UI_GOMIW_*`, `RailUp`, `StockIntegrated` в видимом окне;
- короткий тип оружия разворачивается в читаемое название;
- FN FNC integrated stock имеет читаемое имя и fallback-иконку вместо `?`;
- состояние folded/deployed остаётся рабочим.

## 10. Tooltip насадок

Навести на несколько GoM WeaponPart/магазинов.
