# Homemade Suppressors — баланс Fix 3.9

## Рабочее состояние

| Тип | Шум | Обычный урон | Дальность | Шанс крита | Крит. урон |
|---|---:|---:|---:|---:|---:|
| Пластиковый | -45% | -10% | -10% | -10% | без изменения |
| Баночный | -55% | -10% | -10% | -10% | без изменения |
| Трубный | -65% | -10% | -10% | -10% | без изменения |

## Последний выстрел (Critical)

Остальные штрафы остаются рабочими, меняется только эффективность глушения:

| Тип | Шум | Обычный урон | Дальность | Шанс крита |
|---|---:|---:|---:|---:|
| Пластиковый | -25% | -10% | -10% | -10% |
| Баночный | -35% | -10% | -10% | -10% |
| Трубный | -45% | -10% | -10% | -10% |

При этом последний выстрел теперь **тоже использует приглушённый звук**, а не возвращается к обычному выстрелу.

## После поломки

### Пластиковый
- снимается с оружия;
- создаётся сломанный пластиковый глушитель;
- кладётся на текущую клетку игрока;
- если floor-drop не удался, предмет гарантированно возвращается в инвентарь;
- после снятия оружию ничего не штрафует.

### Баночный / трубный
Остаются на оружии:
- шум: **+10%** относительно оружия без глушителя;
- обычный урон: **-20%**;
- дальность: **-20%**;
- шанс критической атаки: **-10%**;
- множитель критического урона: **-20%**.

## Прочность
Без изменений:
- пластик: 10–30 при Maintenance 1, +1/+1 за уровень выше;
- банка: 40–80 при Maintenance 3, +2/+2 за уровень выше;
- труба: 90–160 при Maintenance 5, +3/+3 за уровень выше.

Каждый выстрел снимает 1 condition. При остатке 1 предмет переходит в Critical.
Следующий выстрел ломает его.
