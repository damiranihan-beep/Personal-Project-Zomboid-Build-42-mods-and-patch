REALISTIC COMBAT — FIX 3.3
Дата: 14.08.2026
Цель: Project Zomboid Build 42.20.2

ИСПРАВЛЕНО
- Убрано прямое player:getAttackVars():clear(), которое в B42.20.2 падало на Java AttackVars.
- Отмена второй атаки теперь сбрасывает только наше Lua-состояние и штатные флаги игрока.
- Для атаки левой рукой подстановка Hand_L / ForeArm_L / UpperArm_L больше не откатывается сразу после pressedAttack().
- Подстановка сохраняется до OnWeaponSwing, то есть до момента, когда ваниль уже выбрала оружие и рассчитала параметры атаки.
- После этого реальные части тела немедленно возвращаются на свои места.
- Все аварийные/reset пути также гарантированно возвращают BodyDamage в нормальный порядок.

ЗАЧЕМ
Предыдущий Fix 3.2 хотел использовать ванильный штраф скорости от травм левой руки,
но мог возвращать BodyDamage слишком рано. Из-за этого царапины/раны на левой кисти,
предплечье или плече могли не влиять на скорость off-hand атаки.

ПРОВЕРИТЬ В ИГРЕ
1. Здоровая левая рука: обычная скорость второй атаки.
2. Царапина на левой кисти: сравнить вторую атаку с первой.
3. Травма левого предплечья/плеча: штраф второй руки должен быть заметнее.
4. Проверить нож, молоток и одноручный топор.
5. Удержание атаки: правая -> левая -> правая -> левая.
6. Отпустить атаку в момент перехода на левую — ERROR-счётчик не должен расти.
7. Проверить промах, попадание, смену оружия и отталкивание.


FIX 3.2
- AttackCollisionCheck для удара и укола второй рукой перенесён с 60%% анимации на 25%% — то же окно, что у ванильной одноручной атаки Build 42.
- Это убирает наблюдаемую задержку урона примерно на 0,5 секунды после визуального удара, не вводя собственный расчёт урона.

ФИКС 3.1
- У настоящего двуручного оружия скрыты пункты контекстного меню для экипировки в одну руку.
- Пункт экипировки в обе руки остаётся.
- Само правило двуручности по-прежнему берётся из игровых флагов предмета.

ФИКС 3
- Двуручное ближнее оружие теперь принудительно занимает обе руки.
- Правило берётся из ванильных флагов TwoHandWeapon/RequiresEquippedBothHands, без списка оружия вручную.
- Dual Wield остаётся только для двух разных реально одноручных оружий.
- Левая атака по-прежнему проходит через ванильный pressedAttack: навыки, выносливость и общие состояния персонажа считаются ванилью.
- Для скорости атаки левой руки используются ранения/боль/скованность левой руки; мышечная нагрузка переносится на левую руку.

REALISTIC COMBAT — ЖУРНАЛ ИЗМЕНЕНИЙ
Project Zomboid Build 42.20.2
ID мода: DualWieldingLite_B42


ФИКС 2 — 2026-08-11
- Переделан запуск чередования: после первого штатного удара мод временно блокирует только автоматический input-driven повтор правой руки.
- Следующие удары основной и второй рукой запускаются напрямую через vanilla CombatManager/pressedAttack после возврата WeaponReady.
- Это устраняет гонку, из-за которой удерживаемая ЛКМ успевала снова запустить правую руку и off-hand анимация вообще не начиналась.
- При отпускании атаки, shove/grapple, смене/поломке оружия или любом сбросе управление немедленно возвращается ванильной системе.
- Сохранён настоящий SwipeStatePlayer для второй руки: попадание, звук оружия, урон, отбрасывание и прочие боевые последствия остаются ванильными.
- Мышечное напряжение off-hand: после подтверждённого столкновения переносится ровно та прибавка скованности, которую B42.20.2 начислил правой руке, на соответствующие части левой руки.
- Добавлены ограниченные диагностические строки в лог для первых трёх запусков off-hand и первых трёх переносов мышечного напряжения.
- Версия в менеджере: 1.2; ID DualWieldingLite_B42 сохранён.


ФИКС 1 — 2026-08-11
- Исправлена главная проблема цепочки атак: следующий удар больше не запускается прямо из OnPlayerAttackFinished.
- После завершения удара мод ждёт возврата штатного player:isWeaponReady(), затем запускает следующую руку через OnPlayerUpdate.
- Это должно устранить ситуацию, когда удержание атаки останавливалось после первого удара основной рукой.
- Сохраняется схема: основная рука -> левая рука -> основная -> левая при удержании кнопки атаки.
- Off-hand по-прежнему проходит через штатный SwipeStatePlayer/CombatManager с характеристиками и звуком фактического оружия второй руки.
- Сохранены проверки левой руки: её повреждения/боль участвуют в расчёте скорости, а ванильная мышечная скованность off-hand переносится на левую руку.
- Shove, stomp, grapple и атаки по лежащим не захватываются циклом двойной атаки.
- Добавлена страховка на прерванный временный swap рук и прекращение цепочки при отпускании атаки/неподходящем оружии.
- Версия в менеджере: 1.1; ID DualWieldingLite_B42 не изменён.

ТЕКУЩАЯ КОНЦЕПЦИЯ
- Новое отображаемое имя: Realistic Combat.
- ID мода сохранён без изменений для совместимости.
- Никаких новых трейтов, перков или отдельных боевых навыков.
- Никакой отдельной кулачной боёвки.
- Работает с двумя разными одноручными оружиями ближнего боя.

БОЁВКА
- При удержании кнопки атаки удары чередуются:
  основная рука -> вторая рука -> основная -> вторая.
- Атака второй рукой проходит через штатный SwipeStatePlayer/vanilla combat pipeline,
  а не через отдельный самописный расчёт попадания.
- Для второй руки временно подставляется её оружие в штатную систему боя,
  после запуска удара расположение предметов в руках восстанавливается.
- Оружие второй руки сохраняет собственные характеристики, звук, столкновение и попадание.
- Колющие и рубящие/ударные атаки второй рукой различаются отдельными условиями анимации.

РЕАЛИСТИЧНЫЕ ДЕБАФЫ
- Для атаки второй рукой штатный расчёт скорости временно читает реальные повреждения,
  боль и мышечную скованность ЛЕВОЙ руки вместо правой.
- Мышечная усталость/скованность, которую ваниль начисляет атакующей руке,
  переносится с правой руки на левую только для фактической off-hand атаки.
- Размер дебафа не придуман модом: переносится именно величина, начисленная ванильной системой.

СОХРАНЁННАЯ ВАНИЛЬНАЯ МЕХАНИКА
- Shove/толкание остаётся штатным.
- Stomp/добивание ногой остаётся штатным.
- Grapple не перехватывается циклом двойной атаки.
- Атаки по лежащим не форсируются второй рукой.
- При отпускании кнопки атаки цепочка немедленно прекращается.
- Если оружие сломалось, стало двуручным или предметы в руках перестали подходить,
  цикл прекращается и управление возвращается ванильной системе.

АНИМАЦИИ
- Добавлены отдельные off-hand AnimSet-узлы для stab и swing.
- Используется отдельная анимационная переменная DWL_Offhand и флаг DWL_OffhandStab.
- Включено защитное восстановление рук, если атака была прервана до штатного события OnWeaponSwing.
