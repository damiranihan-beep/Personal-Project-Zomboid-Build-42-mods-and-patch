REALISTIC COMBAT — ЖУРНАЛ ИЗМЕНЕНИЙ
Project Zomboid Build 42.20.2
ID мода: DualWieldingLite_B42

ТЕКУЩАЯ КОНЦЕПЦИЯ
- Новое отображаемое имя: Realistic Combat.
- ID мода сохранён без изменений для совместимости.
- Никаких новых трейтов, перков или отдельных боевых навыков.
- Никакой отдельной кулачной боёвки.
- Работает с двумя разными одноручными оружиями ближнего боя.

БОЁВКА
- При удержании кнопки атаки удары чередуются:
  основная рука -> вторая рука -> основная -> вторая.
- Атака второй рукой проходит через штатный SwipeStatePlayer/vanilla combat pipeline,
  а не через отдельный самописный расчёт попадания.
- Для второй руки временно подставляется её оружие в штатную систему боя,
  после запуска удара расположение предметов в руках восстанавливается.
- Оружие второй руки сохраняет собственные характеристики, звук, столкновение и попадание.
- Колющие и рубящие/ударные атаки второй рукой различаются отдельными условиями анимации.

РЕАЛИСТИЧНЫЕ ДЕБАФЫ
- Для атаки второй рукой штатный расчёт скорости временно читает реальные повреждения,
  боль и мышечную скованность ЛЕВОЙ руки вместо правой.
- Мышечная усталость/скованность, которую ваниль начисляет атакующей руке,
  переносится с правой руки на левую только для фактической off-hand атаки.
- Размер дебафа не придуман модом: переносится именно величина, начисленная ванильной системой.

СОХРАНЁННАЯ ВАНИЛЬНАЯ МЕХАНИКА
- Shove/толкание остаётся штатным.
- Stomp/добивание ногой остаётся штатным.
- Grapple не перехватывается циклом двойной атаки.
- Атаки по лежащим не форсируются второй рукой.
- При отпускании кнопки атаки цепочка немедленно прекращается.
- Если оружие сломалось, стало двуручным или предметы в руках перестали подходить,
  цикл прекращается и управление возвращается ванильной системе.

АНИМАЦИИ
- Добавлены отдельные off-hand AnimSet-узлы для stab и swing.
- Используется отдельная анимационная переменная DWL_Offhand и флаг DWL_OffhandStab.
- Включено защитное восстановление рук, если атака была прервана до штатного события OnWeaponSwing.
